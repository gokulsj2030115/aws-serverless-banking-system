About Banking Portal
Cloud-Native Serverless Design

This client banking application is designed as a secure static web panel, suitable for direct hosting inside an Amazon S3 Static Website Bucket and distribution via Amazon CloudFront. All logic is computed inside the browser utilizing modern asynchronous fetch() requests.

Architecture Schema
S3 Static Web API Gateway REST AWS Lambda
Data Layer: Amazon DynamoDB
Deployment Instructions
  1. Create a REST API in Amazon API Gateway.
  2. Create backing AWS Lambda functions to process:
    • GET /accounts, POST /accounts
    • POST /accounts/{id}/deposit, POST /accounts/{id}/withdraw
    • POST /transfer, GET /transactions
  3. Deploy your API Gateway stage, copy the Stage Invoke URL, and paste it into the endpoint settings form.
  4. Configure CORS policies on API Gateway to accept origin headers from your hosted domain or local environment.
